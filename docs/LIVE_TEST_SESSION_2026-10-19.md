Target: retail PS5 Lua loader at `10.0.0.96:9026`. The user will relaunch the game if it crashes. Each sender invocation uses `--save --metadata` so the raw console response, transport status, probe SHA-256, and timestamps are retained. A `COMPLETE` transport status means the loader returned output and closed; it does not mean the probe's hypothesis succeeded.
